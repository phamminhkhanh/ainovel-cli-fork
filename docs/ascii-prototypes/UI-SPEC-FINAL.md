# ainovel-cli · UI v4 — FINAL Design Spec

> **Version:** 4.0 (Final)
> **Date:** 2026-08-13
> **Based on:** v2 proposal + v3 feature-complete + 2 QA reviews + backend audit

---

## 📋 DECISION LOG

| Question | Decision | Rationale |
|----------|----------|-----------|
| Market Radar | **Option C — 9 tabs riêng biệt** | Rõ ràng nhất, System Radar ≠ Market Radar |
| Sidebar collapse | **Manual toggle + floating button** | Tránh confuse khi auto-collapse theo tab |
| Profile Studio | **Full-page view từ Production tab** | Match current Production Cockpit pattern |
| Cocreate | **Modal** | Complex workflow, cần focused attention |
| Arc grouping | **UI calc** | Backend returns per-chapter, UI group được |
| Keyboard shortcuts | **Mnemonic keys (S/C/O/W/R/D/M/P/H)** | Tránh conflict với browser shortcuts |

---

## 🎯 FINAL TAB STRUCTURE (9 Tabs)

```
┌────────────────────────────────────────────────────────────────────────────────┐
│ [Stream][Chương][Outline][World][Review][⚡System][📡Market][Sản xuất][Hỗ trợ] │
└────────────────────────────────────────────────────────────────────────────────┘

Tabs:
1. Stream    — Real-time writing preview
2. Chương   — Chapter reader (committed + draft)
3. Outline  — Premise + outline + compass
4. World    — Characters + foreshadow + rules
5. Review   — 7-dimension analysis per chapter/arc
6. ⚡System — Health + agents + costs + events (System Radar)
7. 📡Market — Fanqie/Qidian analysis + recommendations
8. Sản xuất — Production Jobs + Profile Library + Studio
9. Hỗ trợ  — Quick guide + shortcuts + FAQ
```
